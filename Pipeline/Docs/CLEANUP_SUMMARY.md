## Maintenance

### Regular Cleanup
Run cleanup script periodically:
```bash
# Before each git push
./cleanup.sh --cache --dry-run  # Preview
./cleanup.sh --cache            # Execute

# Deep clean (remove all generated files)
./cleanup.sh --all --dry-run    # Preview
./cleanup.sh --all              # Execute
```

### Adding New Files to Ignore
If you generate new types of output files, update `.gitignore`:
```bash
# Edit .gitignore to add new patterns
nano .gitignore

# Test what git sees
git status --short
git check-ignore -v <path/to/file>
```
