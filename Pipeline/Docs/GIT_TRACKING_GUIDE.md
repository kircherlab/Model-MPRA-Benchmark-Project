## 💡 Best Practices

1. **Never commit large files** (>100MB)
   - Data files should be downloaded/generated
   - Document data sources in README

2. **Keep results local**
   - Results are generated by running the pipeline
   - Share results via publications or data repositories

3. **Version control for code only**
   - Scripts
   - Configs
   - Documentation
   - Environment specifications

4. **Use Git LFS for necessary large files** (if absolutely needed)
   ```bash
   git lfs track "*.h5"
   ```

## 🔍 Testing Gitignore

Test if a file will be ignored:
```bash
git check-ignore -v path/to/file
```

List all ignored files:
```bash
git status --ignored
```
